🚪 Парадокс Монти Холла: проверь интуицию

Ты уверен, что знаешь, как работают шансы? Попробуй этот мини-проект — он покажет, насколько интуиция может обманывать в теории вероятностей.

Здесь можно сыграть в классическую задачу про три двери и автомобиль, а ещё запустить автоматическую симуляцию на 1000 раундов, чтобы увидеть, как статистика подтверждает математику.

## Что внутри

- Игра по правилам парадокса Монти Холла.
- Подсчёт побед и поражений, расчёт текущей вероятности.
- Кнопка «1000 игр» — быстрая симуляция, чтобы увидеть сходимость к 66,7%.
- Простая визуализация на Canvas: двери, машина, коза, маркер выбора.

## Почему это круто

Парадокс Монти Холла регулярно ставит в тупик даже опытных математиков и программистов. Этот проект — отличный способ увидеть теорию в действии. Идеально для уроков математики, кружков по программированию и просто для любопытства.

## Как попробовать

Просто открой `index.html` в браузере (лучше через локальный сервер, чтобы картинки отображались корректно). Никаких установок и зависимостей — чистый HTML/CSS/JS.

## Технические детали

- Frontend: HTML5, CSS3, JavaScript.
- Отрисовка: HTML5 Canvas.
- Симуляция: чистая JS-логика без внешних библиотек.
